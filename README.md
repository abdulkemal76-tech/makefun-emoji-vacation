# One Emoji, One Dream Vacation

Entry for the make.fun bounty [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): a program that writes exactly one emoji — the one most likely to make a stranger want to book the flight — to `/output/entry.txt`.

## The emoji

🗻 Mount Fuji

A mountain and a faraway place in a single glance: one concrete, named dream (Japan at dawn) instead of any generic holiday. It reads instantly at any size, and at 4 UTF-8 bytes it is the smallest possible entry of its kind.

## Run

```sh
python3 main.py
```
